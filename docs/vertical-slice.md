# Luminhive Skygarden vertical slice

This folder starts the playable visual prototype for Luminhive Skygarden.

## First playable scope

- Floating Skygarden with a massive luminous hive tree.
- Golden honeycomb cells, lanterns, small hive structures, waterfalls, bridges, clouds, flowers, and bees.
- Third-person player movement on the starter island.
- Lumens auto-collect pollen from flowers and convert it into honey.
- Flowers implement the v1 four-phase efficiency model: Full Bloom, Fading, Drained, Exhausted.
- Bloom Chain ability: a Lumen pulses, the player touches it to start, then routes through the swarm with a 5 second reset timer.

## Visual direction

The scene uses a stylized high-fantasy look: saturated blue sky, warm honey glow, soft bloom, dense flowers and grass, floating islands, and an oversized central hive tree. It is not a copy of any existing game art, but it targets the same readable, polished, anime-fantasy presentation quality.

## Run

```bash
npm install
npm run dev
```
